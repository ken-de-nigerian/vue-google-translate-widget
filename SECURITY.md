# Security Policy

## Supported versions

Only the latest minor release receives security fixes.

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately through
[GitHub Security Advisories](https://github.com/ken-de-nigerian/vue-google-translate-widget/security/advisories/new)
with steps to reproduce and the affected version.

You'll get an acknowledgement within 72 hours. Once a fix is released, the advisory is published and you're
credited unless you'd rather not be.

## Scope

This package loads Google's Website Translator script (`translate.google.com`) and reads and writes the
`googtrans` cookie. Issues in Google's own script are out of scope; report those to Google.
